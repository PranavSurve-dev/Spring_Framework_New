# Spring Framework

This repository contains my learning and practice programs for the **Spring Framework** as part of my Java Full Stack Development training.

## 📚 Topics Covered

* Introduction to Spring Framework
* Spring Architecture
* Spring Container
* IoC (Inversion of Control)
* Dependency Injection (DI)
* Tight Coupling and Loose Coupling
* Spring Configuration
* XML Configuration
* Spring Beans
* BeanFactory
* ApplicationContext
* Constructor Dependency Injection
* Setter Dependency Injection
* Autowiring
* Bean Scope
* Spring Annotations
* Component Scanning
* `@Component`
* `@Autowired`
* `@Qualifier`
* `@Primary`
* `@Configuration`
* `@Bean`
